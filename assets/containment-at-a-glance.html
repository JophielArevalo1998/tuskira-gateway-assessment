  • The attacker — our test script (live_attack.py)

  • The bridge — glue we built for this test (not part of either tool)

The gateway denies, logs, and exposes a revoke API — but it never detects patterns or responds on its own. AiSOC investigates and recommends, but touches nothing. The bridge is what ties them into a closed loop: it watches, decides, and executes. In a real SOC that role is a SOAR platform.
